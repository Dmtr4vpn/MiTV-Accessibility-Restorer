ДЕКОМПИЛЯЦИЯ PROJECTIVY
----------------------

Установленный APK Projectivy был получен read-only через `pm path` + `adb pull`
и проанализирован JADX.

Точная цепочка:

1. `defpackage.db3.f(ActivityInfo)` вызывает
   `activityInfo.getBannerResource()`.
2. При отсутствии banner используется `activityInfo.getIconResource()`.
3. `db3.i()` / `db3.k()` формирует URI:
   `android.resource://<package>/<decimal-resource-id>`.
4. `defpackage.ib.r()` возвращает этот URI карточке приложения.
5. `defpackage.ss.l()` передаёт URI Glide request.
6. Glide disk cache располагается во внутреннем каталоге Projectivy:
   `/data/user/0/com.spocky.projengmenu/cache/image_manager_disk_cache`.

Для v18 model/cache URI был:

android.resource://com.mitv.accessibilityrestorer/2130771968

где 2130771968 = 0x7f010000.

`run-as com.spocky.projengmenu` недоступен: release APK не debuggable. Поэтому
shell не имеет доступа к имени отдельного внутреннего cache-файла. Никакой файл
или БД Projectivy наугад не удалялись.

ИСПРАВЛЕНИЕ
-----------

Bitmap FOX не изменён. Ресурс переименован в `restorer_banner_fox`, а прозрачный
служебный drawable занимает прежний ID. Активный banner v19:

- resource ID -> 0x7f010001;
- URI -> android.resource://com.mitv.accessibilityrestorer/2130771969;
- packaged file -> res/drawable-nodpi-v4/restorer_banner_fox.png;
- размер -> 640x360;
- SHA-256 -> F6C4CD01AF457C59A7BA3B2AC12A06032F793F21F1917C56CFC61FDF86890158.

Старый Glide cache entry не удалён физически: он безопасно инвалидирован сменой
model URI и больше не выбирается для Restorer. Это сохраняет весь Projectivy
cache и пользовательские настройки остальных приложений.

ФАКТИЧЕСКАЯ ПРОВЕРКА
-------------------

После `adb install -r` v19 выполнены только:

adb shell am force-stop com.spocky.projengmenu
adb shell am start -n com.spocky.projengmenu/.ui.home.MainActivity

Реальная XS-карточка на экране 1920x1080 показывает вертикальную надпись FOX.
Обычные карточки продолжают использовать то же FOX artwork.

pm clear com.spocky.projengmenu = NOT EXECUTED
Projectivy database deletion = NOT EXECUTED
Projectivy SharedPreferences deletion = NOT EXECUTED
Projectivy reinstall = NOT EXECUTED
