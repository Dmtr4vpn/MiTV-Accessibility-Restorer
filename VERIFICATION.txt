DIAGNOSTIC VERSION
------------------

Hardcoded RecoveryEngine VERSION_NAME/VERSION_CODE удалены.

AppVersion.read(context) использует фактический PackageInfo:

- PackageManager.getPackageInfo(context.getPackageName(), 0);
- PackageInfo.versionName;
- PackageInfo.getLongVersionCode() на API 28+;
- PackageInfo.versionCode на старых API.

ControlActivity и RecoveryEngine SESSION START используют один AppVersion helper.
javap/dexdump подтвердили PackageInfo call и отсутствие hardcoded versionCode 12,
13 или 14 в diagnostic code.

Следовательно после установки этого APK:

- dumpsys package -> versionCode=14;
- SESSION START -> versionCode=14.

Фактический logcat readback проверяется на ТВ.
