MiTV Accessibility Restorer 4.0.0 - verification
================================================

Статус: production APK собран официальным Android toolchain, подписан прежним
ключом и статически проверен. Объединённый релиз 4.0.0 не запускался Codex на
физическом Xiaomi Mi TV S75; фактические Bound/Crashed, VPN, native torrserver,
Home remap и визуальный путь должны быть проверены пользователем.

STR Accessibility plan
----------------------

Сохранены interactive settle 500 ms и обязательный порядок:

- ALL INITIAL: 2500 ms
- BASE: 1500 ms
- MAPPER: 2500 ms
- ALL FINAL: 1500 ms

Normal profile: NORMAL_9S. При измеримой ошибке допускается одна conservative
attempt после паузы 1000 ms с timings 4000/3000/3000/3000. Максимум 2 attempts.

BASE удаляет только три managed target и сохраняет остальные raw tokens и их

не влияет на основной execution result.


TorrServe
---------

Добавлен отдельный STR-only `TorrServeTarget`:

- проверяет `ru.yourok.torrserve`;
- проверяет точный GlobalTorrService и BIND_ACCESSIBILITY_SERVICE;
- не запускает Activity;
- не вызывает BCReceiver;
- не выполняет отдельный unstop;
- логирует packageInstalled, accessibilityTargetAvailable,
  accessibilitySkipped, includedInAllInitial=false, includedInAllFinal и
  expectedAutoStartViaAccessibility.

APK не утверждает, что TorrServe Bound; это проверяется через dumpsys на ТВ.


v2RayTun VPN assist
-------------------

Добавлен STR-only `V2RayVpnAssist`, который запускается отдельным потоком
параллельно Accessibility recovery. RecoveryEngine не ждёт helper перед final
Projectivy, а VPN status является advisory и не входит в execution result.

Логика решения:

1. Package missing -> SKIPPED_PACKAGE_MISSING.
2. Любой TRANSPORT_VPN active -> ALREADY_ACTIVE, trigger не отправляется.
3. stopped=true и VPN отсутствует -> повторная VPN-проверка и один trigger.
4. stopped=false и VPN отсутствует -> grace 2000 ms, повторная проверка VPN и
   FLAG_STOPPED, затем ещё одна VPN-проверка непосредственно перед trigger.
5. После trigger: poll 250 ms, timeout 5000 ms, CONNECTED или TIMEOUT.

Action/component:

- com.v2raytun.android.action.widget.click
- com.v2raytun.android/.receiver.WidgetProvider1x1
- Intent.FLAG_INCLUDE_STOPPED_PACKAGES

DEX-блок V2RayVpnAssist содержит ровно одну ссылку sendBroadcast. UI v2RayTun не
запускается, v2RayTun не добавляется в enabled_accessibility_services.

Известные ограничения
---------------------

- Новый объединённый релиз не проверялся Codex на физическом телевизоре.
- Реальный Bound/Binding/Crashed определяется только dumpsys accessibility.
- Наличие native torrserver и VPN/tun0 определяется системными командами.
- Любой уже активный VPN transport безопасно подавляет v2RayTun toggle.
- Target receiver/service components зависят от установленных версий приложений.
- Emergency visible fallback может показать промежуточный кадр.
