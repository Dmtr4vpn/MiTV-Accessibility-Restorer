MiTV Accessibility Restorer 4.0.0 - STATIC VERIFICATION
=======================================================

Дата локальной проверки: 2026-09-05

ВАЖНО
------

Пользователь физически подтвердил успешный cold boot сборки versionCode 12 на
Xiaomi Mi TV S75, MiTV OS 2.8.1712, Android 11: core recovery, Projectivy,
TorrServe и v2RayTun завершились успешно.

VersionCode 13 исправляет только маршрутизацию пользовательского запуска и ещё
не проверялся на физическом телевизоре. Для него обязательны три acceptance-
теста: cold boot, STR Sleep -> Wake и User Open. GitHub Release не опубликован.

ФИЗИЧЕСКИЙ ACCEPTANCE TEST
--------------------------

До публикации выполнить только три теста.

A. Cold boot:

- EARLY_BOOT SUCCESS;
- Projectivy foreground;
- после BOOT_COMPLETED TorrServe RECOVERED/ALREADY_ENABLED;
- v2RayTun CONNECTED/ALREADY_ACTIVE.

B. STR Sleep 30 sec -> Wake:

- RecoveryCover;
- STR SESSION START;
- Mapper/Projectivy/TorrServe/v2RayTun recovery;
- SESSION FINISH COMPLETED;
- Projectivy foreground;
- ControlActivity не появляется.

C. User Open:

- Settings «Открыть» -> ControlActivity без recovery;
- Android TV/Projectivy card -> ControlActivity через LEANBACK_LAUNCHER;
- LAUNCHER resolve -> MainActivity;
- LEANBACK_LAUNCHER resolve -> ControlActivity;
- INFO resolve -> ControlActivity.

Release blocker: STR -> ControlActivity, отсутствие SESSION, Bound={} или Crashed
у Mapper/Projectivy/TorrServe. GitHub Release до физического acceptance test не
публиковать.
