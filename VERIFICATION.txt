Installer flow
--------------

INSTALL.cmd versionCode decisions are unchanged:

package absent -> adb install
installed versionCode lower -> adb install -r
same versionCode -> skip install
installed versionCode higher -> no automatic downgrade

The final configure_restorer flow runs even after same-version skip:

1. Locate com.mitv.accessibilityrestorer.
2. Grant WRITE_SECURE_SETTINGS and verify granted=true readback.
3. Verify flar2.homebutton and com.spocky.projengmenu with pm path.
4. Run only am force-stop com.spocky.projengmenu; no data is cleared.
5. Start existing recovery with am start -W -n
   com.mitv.accessibilityrestorer/.MainActivity.
6. Poll once per second for up to 30 seconds.
7. Require both target components in enabled_accessibility_services.
8. Parse only the Bound services section of dumpsys accessibility and require
   Button Mapper plus Projectivy Launcher/package there.
9. Send KEYCODE_HOME with adb shell input keyevent 3.
10. Wait 1250 ms and inspect mCurrentFocus/mFocusedApp from dumpsys window.
11. Require Projectivy home foreground:
    com.spocky.projengmenu/com.spocky.projengmenu.ui.home.MainActivity
12. Open com.mitv.accessibilityrestorer/.ControlActivity last.

TorrServe and v2RayTun do not participate in installer success criteria.
