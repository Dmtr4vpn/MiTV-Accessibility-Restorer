INSTALL.cmd readiness and HOME test
-----------------------------------

The installation/versionCode algorithm is unchanged. After the existing
Projectivy force-stop and explicit MainActivity bootstrap, READY now requires
all five conditions simultaneously:

1. Button Mapper is in enabled_accessibility_services.
2. Projectivy is in enabled_accessibility_services.
3. Button Mapper is in the Bound services section.
4. Projectivy is in the Bound services section.
5. Foreground is Projectivy home MainActivity.

All five conditions must pass 2 consecutive polling cycles. Poll interval is
1000 ms and total timeout is 30 cycles/seconds. Any failed poll resets the
readiness streak to zero.

After the second successful poll:
wait 1500 ms
send adb shell input keyevent 3
wait 1500 ms
read mCurrentFocus/mFocusedApp from dumpsys window

HOME succeeds only for:
com.spocky.projengmenu/com.spocky.projengmenu.ui.home.MainActivity
or the equivalent short activity notation.

No Projectivy am start occurs after READY. No pm clear, app reinstall or HOME
settings write was added.

Projectivy XS source audit
--------------------------

Installed read-only audit target:
Projectivy Launcher versionName=4.71, versionCode=95.

Its card image path first returns a per-card custom artwork URI when one exists.
Otherwise the card binder calls the shared ActivityInfo resource selector. DEX
disassembly proves that selector is controlled by preference key
key_launcher_card_tv_app_aspect_ratio:

TV aspect ratio != ASPECT_RATIO_1_1 (including 16:9)
-> ActivityInfo.getBannerResource()
-> ActivityInfo/ApplicationInfo banner
-> icon only if banner resource is zero

TV aspect ratio == ASPECT_RATIO_1_1
-> ActivityInfo.getIconResource()

Card size XS is not used in this source-selection method. Therefore Projectivy
XS cannot select a second Restorer APK banner variant: none exists. If XS does
not show the FOX banner, its actual source is either configured per-card custom
artwork/cache or the launcher icon selected by 1:1 TV-app aspect ratio. The
approved square icon 3.1.png was not changed.
