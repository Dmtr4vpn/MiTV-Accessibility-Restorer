FOX MiTV Restorer 4.0.0
=======================

Версия: 4.0.0 (versionCode 19)
Package: com.mitv.accessibilityrestorer
Проверенная платформа: Xiaomi Mi TV S75, MiTV OS 2.8.1712, Android 11

СТАНДАРТНАЯ УСТАНОВКА
---------------------

Подготовьте папку:

ADBAppControl-1.8.6\
  INSTALL.cmd
  adb\adb.exe
  install\FOX-MiTV-Restorer-4.0.0.apk
  install\другие-приложения.apk

1. Включите ADB debugging на телевизоре.
2. Запустите INSTALL.cmd.
3. При отсутствии соединения следуйте подсказкам для IP/порта или Wireless
   Debugging pairing.
4. При первом соединении подтвердите RSA-доступ на телевизоре.
5. Дождитесь итогового резюме.

INSTALL.cmd очищает INSTALL-LOG.txt при каждом запуске и обрабатывает все APK из
папки install по versionCode:

package отсутствует                 -> INSTALL
installedVersionCode < apkVersion   -> UPDATE через adb install -r
installedVersionCode = apkVersion   -> SKIP INSTALL
installedVersionCode > apkVersion   -> SKIP, downgrade запрещён

Для FOX MiTV Restorer скрипт:

1. Выдаёт и проверяет WRITE_SECURE_SETTINGS.
2. Проверяет Button Mapper и Projectivy Launcher.
3. Перезапускает Projectivy без очистки данных.
4. Запускает com.mitv.accessibilityrestorer/.MainActivity.
5. До 30 секунд опрашивает состояние с интервалом 1000 ms.

READY требует два успешных polling cycle подряд:

- Button Mapper Enabled;
- Projectivy Enabled;
- Button Mapper Bound;
- Projectivy Bound;
- Projectivy home в foreground.

После READY открывается com.mitv.accessibilityrestorer/.ControlActivity.
Синтетическая HOME через ADB не выполняется.

Нажмите физическую кнопку HOME на пульте.
Ожидаемый результат: Projectivy Launcher.

РУЧНАЯ УСТАНОВКА ИЛИ ОБНОВЛЕНИЕ
-------------------------------

adb install -r FOX-MiTV-Restorer-4.0.0.apk
adb shell pm grant com.mitv.accessibilityrestorer android.permission.WRITE_SECURE_SETTINGS
adb shell am start -n com.mitv.accessibilityrestorer/.ControlActivity

Проверьте:

adb shell dumpsys package com.mitv.accessibilityrestorer

Ожидается:

versionCode=19
versionName=4.0.0
android.permission.WRITE_SECURE_SETTINGS: granted=true
stopped=false

ЭКРАН СОСТОЯНИЯ
---------------

При исправной системе экран показывает:

✓ Разрешение управления спецвозможностями — выдано
  WRITE_SECURE_SETTINGS
✓ Button Mapper — спецвозможности включены
✓ Projectivy Launcher — спецвозможности включены
✓ TorrServe — спецвозможности включены (необязательно)
✓ v2RayTun — VPN подключён (необязательно)

Система готова к работе.
Для выхода нажмите HOME.

Статус Bound в UI не показывается. Для его проверки используйте:

adb shell dumpsys accessibility

На экране одна кнопка:

Восстановить спецвозможности

Не нажимайте её, если система уже готова к работе.

ПРОВЕРКА ROUTING
----------------

adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.LAUNCHER com.mitv.accessibilityrestorer
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.LEANBACK_LAUNCHER com.mitv.accessibilityrestorer
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.INFO com.mitv.accessibilityrestorer

Ожидается:

com.mitv.accessibilityrestorer/.MainActivity
com.mitv.accessibilityrestorer/.ControlActivity
No activity found / NO MATCH

ПРОВЕРКА COLD BOOT И STR
-----------------------

Cold boot:

BLACK -> Projectivy

STR:

Sleep -> 30 секунд -> Wake
#474747 -> Projectivy

После каждого сценария проверьте физическую HOME. Она должна открывать
Projectivy Launcher. Не заменяйте эту проверку ADB keyevent.

ДИАГНОСТИЧЕСКИЙ READBACK
------------------------

adb shell settings get secure accessibility_enabled
adb shell settings get secure enabled_accessibility_services
adb shell dumpsys accessibility
adb shell dumpsys connectivity
adb shell dumpsys window

БЕЗОПАСНОСТЬ
------------

Не очищайте данные Button Mapper, Projectivy, TorrServe или v2RayTun при обычной
установке и проверке Restorer. Установщик и приложение не меняют Android default
HOME и не очищают настройки сторонних приложений.
