FOX MiTV Restorer 4.0.0
=======================

Версия: 4.0.0 (versionCode 17)
Package: foxmitv.restorer
Прежний package: com.mitv.accessibilityrestorer

СТАНДАРТНАЯ УСТАНОВКА
---------------------

Подготовьте папку:

ADBAppControl-1.8.6\
  INSTALL.cmd
  adb\adb.exe
  install\FOX-MiTV-Restorer-4.0.0.apk
  install\другие-приложения.apk

1. Включите ADB debugging на телевизоре.
2. Запустите INSTALL.cmd.
3. Если соединение отсутствует, введите IP/порт или выполните Wireless Debugging
   pairing по подсказкам скрипта.
4. Один раз подтвердите RSA-доступ на телевизоре, если появится запрос.
5. Дождитесь итогового резюме.

INSTALL.cmd каждый раз очищает INSTALL-LOG.txt и обрабатывает все APK из
install\ по versionCode:

package отсутствует                 -> INSTALL
installedVersionCode < apkVersion   -> UPDATE через adb install -r
installedVersionCode = apkVersion   -> SKIP INSTALL
installedVersionCode > apkVersion   -> SKIP, downgrade запрещён

При обработке `foxmitv.restorer` скрипт сначала проверяет legacy package
`com.mitv.accessibilityrestorer`. Если он установлен, удаляется только старый
Restorer. Если удалить его не удалось, новый package не устанавливается, чтобы
на ТВ не осталось два автоматических recovery-приложения.

Projectivy, Button Mapper, TorrServe и v2RayTun не удаляются и не очищаются.
Private data старого Restorer не переносится.

POST-INSTALL READY
------------------

После установки или SKIP нового Restorer скрипт:

1. Выдаёт и проверяет WRITE_SECURE_SETTINGS.
2. Проверяет наличие Button Mapper и Projectivy.
3. Выполняет `am force-stop com.spocky.projengmenu` без очистки данных.
4. Запускает `foxmitv.restorer/.MainActivity`.
5. До 30 секунд опрашивает состояние с интервалом 1000 ms.

READY требует пять условий два polling cycle подряд:

- Button Mapper Enabled;
- Projectivy Enabled;
- Button Mapper Bound;
- Projectivy Bound;
- Projectivy home находится в foreground.

После READY сразу открывается `foxmitv.restorer/.ControlActivity`.
Синтетический HOME test через ADB не выполняется.

Итоговое резюме показывает:

FOX MiTV Restorer: installed / not installed
WRITE_SECURE_SETTINGS: granted / ошибка
Core recovery after install: READY / FAILED / CORE_MISSING
Button Mapper bound: YES / NO
Projectivy bound: YES / NO
Старый Restorer: removed / not installed / ошибка
Физическая HOME: проверьте кнопкой пульта
Setup UI: opened / failed

После установки нажмите физическую кнопку HOME на пульте.
Ожидаемый результат: Projectivy Launcher.

РУЧНАЯ МИГРАЦИЯ И УСТАНОВКА
---------------------------

Проверьте и удалите только старый Restorer:

adb shell pm path com.mitv.accessibilityrestorer
adb uninstall com.mitv.accessibilityrestorer
adb shell pm path com.mitv.accessibilityrestorer

Установите новый package без `-r`, выдайте разрешение и явно запустите UI:

adb install FOX-MiTV-Restorer-4.0.0.apk
adb shell pm grant foxmitv.restorer android.permission.WRITE_SECURE_SETTINGS
adb shell dumpsys package foxmitv.restorer | grep -iE "versionCode|versionName|WRITE_SECURE_SETTINGS|stopped"
adb shell am start -n foxmitv.restorer/.ControlActivity

Ожидается:

versionCode=17
versionName=4.0.0
android.permission.WRITE_SECURE_SETTINGS: granted=true
stopped=false
notLaunched=false

ПРОВЕРКА ПОЛЬЗОВАТЕЛЬСКОГО ЭКРАНА
---------------------------------

ControlActivity автоматически обновляет статусы при открытии и возврате в окно.
На одном экране должны быть видны WRITE_SECURE_SETTINGS, Button Mapper,
Projectivy Launcher, optional TorrServe, optional v2RayTun/VPN, общий результат
и подсказка `Для выхода нажмите HOME.`.

Должна быть ровно одна action-кнопка:

Восстановить спецвозможности

Кнопки `Проверить снова`, `Завершить настройку`, `Диагностика` и
`Восстановить сейчас` отсутствуют. Не нажимайте manual recovery, если экран уже
показывает `Система готова к работе.`.

ПРОВЕРКА ROUTING
----------------

adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.LAUNCHER foxmitv.restorer
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.LEANBACK_LAUNCHER foxmitv.restorer
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.INFO foxmitv.restorer

Ожидается:

foxmitv.restorer/.MainActivity
foxmitv.restorer/.ControlActivity
No activity found / NO MATCH

ПРОВЕРКА ПЕРЕД COLD BOOT
------------------------

adb shell settings get secure enabled_accessibility_services
adb shell settings get secure accessibility_enabled
adb shell dumpsys accessibility
adb shell dumpsys connectivity

Button Mapper, Projectivy и TorrServe должны быть Enabled/Bound при наличии
пакетов. `Binding services:{}` и `Crashed services:{}` должны быть пустыми.

COLD BOOT
---------

После полного выключения и включения ожидается:

BLACK -> Projectivy

Автоматический recovery не должен показывать ControlActivity. После загрузки:

adb shell settings get secure enabled_accessibility_services
adb shell settings get secure accessibility_enabled
adb shell dumpsys accessibility
adb shell dumpsys connectivity
adb shell "logcat -d | grep -iE 'MiTVRestorer|foxmitv.restorer|AndroidRuntime'"

Ожидаются core SUCCESS, Projectivy foreground, Button Mapper/Projectivy Bound.
TorrServe и v2RayTun остаются optional.

STR REGRESSION
--------------

Sleep -> 30 секунд -> Wake

Визуально:

#474747 -> Projectivy

Проверенные тайминги:

interactive settle = 500 ms
ALL_INITIAL        = 2500 ms
BASE               = 1500 ms
MAPPER             = 2500 ms
ALL_FINAL          = 1500 ms

После STR:

adb shell settings get secure enabled_accessibility_services
adb shell dumpsys accessibility
adb shell dumpsys connectivity
adb shell "logcat -d | grep -iE 'STR TIMING|STR RESET|V2RAY|MiTVRestorer|AndroidRuntime'"

SESSION START и dumpsys package должны показывать versionCode=17.
ControlActivity во время автоматического STR появляться не должна.

БЕЗОПАСНОСТЬ
------------

Не выполнять для связанных приложений:

pm clear flar2.homebutton
pm clear com.spocky.projengmenu
pm clear ru.yourok.torrserve
pm clear com.v2raytun.android

Не записывать `Settings.System.start_3rd_app`: Restorer читает его только как
advisory. Не использовать ADB-инъекцию HOME как замену физической кнопке пульта.

Проверка package/UI versionCode 17 выполнена на реальном Xiaomi Mi TV S75. После
readback телевизор полностью выключен командой `adb shell reboot -p`; cold boot
после этого выполняет пользователь.
