MiTV Accessibility Restorer 4.0.0
=================================

Версия: 4.0.0 (versionCode 12)
Package: com.mitv.accessibilityrestorer

СТАНДАРТНАЯ УСТАНОВКА
---------------------

Подготовьте папку:

ADBAppControl-1.8.6\
  INSTALL.cmd
  adb\adb.exe
  install\MiTVAccessibilityRestorer-4.0.0.apk
  install\другие-приложения.apk

1. Включите ADB debugging на телевизоре.
2. Запустите INSTALL.cmd.
3. Если устройство ещё не подключено, выберите IP/порт или Wireless Debugging
   pairing и следуйте подсказкам.
4. Один раз подтвердите RSA-доступ на телевизоре, если появится запрос.
5. Дождитесь общего резюме. Скрипт не требует подтверждения каждого APK и не
   останавливается после отдельной ошибки.
6. На телевизоре откроется ControlActivity. Проверьте основные компоненты и
   нажмите «Завершить настройку».

INSTALL.cmd каждый раз очищает INSTALL-LOG.txt, перебирает install\*.apk в
алфавитном порядке и сравнивает package/versionCode:

package отсутствует                 -> INSTALL
installedVersionCode < apkVersion   -> UPDATE через adb install -r
installedVersionCode = apkVersion   -> SKIP INSTALL
installedVersionCode > apkVersion   -> SKIP, automatic downgrade запрещён

После SKIP Restorer всё равно проверяются WRITE_SECURE_SETTINGS, permission
readback и запуск ControlActivity. Автоматический uninstall не выполняется.

Если получено INSTALL_FAILED_UPDATE_INCOMPATIBLE, установленный Restorer подписан
другим ключом. Только после осознанного решения выполните:

adb uninstall com.mitv.accessibilityrestorer

Удаление Restorer не удаляет настройки Projectivy Launcher, Button Mapper,
TorrServe или v2RayTun.

РУЧНАЯ УСТАНОВКА
----------------

Обновление с совместимой подписью:

adb install -r MiTVAccessibilityRestorer-4.0.0.apk
adb shell pm grant com.mitv.accessibilityrestorer android.permission.WRITE_SECURE_SETTINGS
adb shell dumpsys package com.mitv.accessibilityrestorer | grep -i WRITE_SECURE_SETTINGS
adb shell am start -n com.mitv.accessibilityrestorer/.ControlActivity

Стандартная и ручная установка НЕ выполняют:

settings put system start_3rd_app ...

Пустое/null значение start_3rd_app допустимо. Restorer читает его только для
диагностики; MISSING_UNARMED не является ошибкой.

ПЕРВИЧНАЯ ПРОВЕРКА
------------------

adb shell dumpsys package com.mitv.accessibilityrestorer | grep -iE "versionCode|versionName|WRITE_SECURE_SETTINGS"
adb shell settings get secure enabled_accessibility_services
adb shell settings get secure accessibility_enabled
adb shell settings get system start_3rd_app

На экране Restorer:

- Button Mapper и Projectivy Launcher являются обязательными core-компонентами;
- TorrServe и v2RayTun помечены как необязательные;
- отсутствие optional package/component не блокирует «Завершить настройку»;
- «Восстановить сейчас» немедленно запускает ручное восстановление.

ACCEPTANCE: COLD BOOT
---------------------

Эта проверка требует физического отключения питания телевизора. Перед ней
оставьте start_3rd_app пустым/unarmed и не запускайте optional приложения руками.

Очистите старый logcat и выключите ТВ:

adb logcat -c
adb shell settings get system start_3rd_app

После полного отключения питания и завершения загрузки подключите ADB и выполните:

adb shell settings get secure enabled_accessibility_services
adb shell settings get secure accessibility_enabled
adb shell dumpsys accessibility
adb shell dumpsys connectivity
adb shell ps -A | grep -iE "projengmenu|homebutton|torrserve|v2ray"
adb shell "logcat -d | grep -iE 'MiTVRestorer|accessibilityrestorer|AndroidRuntime'"

Ожидаемый core-путь:

BOOT_COUNT changed
-> MAIN DECISION mode=BOOT_PENDING
-> EARLY_BOOT
-> Mapper + Projectivy
-> Projectivy final launch
-> SESSION FINISH success=true

После получения Android BOOT_COMPLETED ожидается ровно один:

POST_BOOT_OPTIONAL gate check ... coreBootSuccess=true ...
POST_BOOT_OPTIONAL_RECOVERY started
POST_BOOT_OPTIONAL_RECOVERY FINISH ...

Если установлен TorrServe, GlobalTorrService должен присутствовать в
enabled_accessibility_services и быть Bound. Его native server/process должен
продолжать работать. Допустимые статусы:

RECOVERED
ALREADY_ENABLED
SKIPPED_NOT_INSTALLED
SKIPPED_COMPONENT_UNAVAILABLE
FAILED

Если установлен v2RayTun, ожидаются V2RayVpnService, VPN transport и tun0 без
ручного запуска приложения. Допустимые статусы:

CONNECTED
ALREADY_ACTIVE
SKIPPED_NOT_INSTALLED
SKIPPED_COMPONENT_UNAVAILABLE
TIMEOUT
TRIGGER_FAILED

Ошибка optional-интеграции не меняет уже записанный core success.

ACCEPTANCE: РУЧНОЕ ОТКРЫТИЕ
---------------------------

После завершённой загрузки откройте:

Настройки -> Все приложения -> MiTV Accessibility Restorer -> Открыть

Либо выполните launcher-entry явно:

adb shell am start -a android.intent.action.MAIN -c android.intent.category.LAUNCHER -n com.mitv.accessibilityrestorer/.MainActivity

Ожидается ControlActivity. Не должны появиться black RecoveryCover,
Accessibility popup, STR/EARLY_BOOT recovery или принудительный Projectivy.

Проверка маршрута:

adb shell "logcat -d | grep -iE 'MAIN DECISION|MAIN ROUTE|MiTVRestorer'"

Ожидаемые строки:

MAIN DECISION ... mode=USER_UI ... reason=no_recovery_required
MAIN ROUTE -> ControlActivity

ACCEPTANCE: STR REGRESSION
--------------------------

После cold-boot и manual-UI тестов выполните обычный цикл:

Sleep -> 30 секунд -> Wake

Ожидается прежний путь:

RecoveryCover
-> Mapper recovery
-> Projectivy recovery
-> TorrServe в ALL_FINAL, если доступен
-> v2RayTun assist, если доступен
-> Projectivy final foreground

Проверенные тайминги должны остаться:

interactive settle = 500 ms
ALL_INITIAL        = 2500 ms
BASE               = 1500 ms
MAPPER             = 2500 ms
ALL_FINAL          = 1500 ms

Проверка после STR:

adb shell settings get secure enabled_accessibility_services
adb shell dumpsys accessibility
adb shell dumpsys connectivity
adb shell "logcat -d | grep -iE 'STR TIMING|STR RESET|V2RAY|MiTVRestorer|AndroidRuntime'"

ФИЗИЧЕСКАЯ ПРОВЕРКА
--------------------

Codex не подключался к реальному телевизору. APK versionCode 12 прошёл сборку и
статическую проверку, но cold boot, manual UI и STR regression должны быть
подтверждены на Xiaomi Mi TV S75 пользователем до публикации GitHub Release.
