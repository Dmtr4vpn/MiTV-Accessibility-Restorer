MiTV Accessibility Restorer 4.0.0
=================================

Версия: 4.0.0 (versionCode 10)
Package: com.mitv.accessibilityrestorer

СТАНДАРТНАЯ УСТАНОВКА
---------------------

1. Включите ADB debugging в настройках телевизора.
2. Подключите Xiaomi Mi TV S75 к ПК и подтвердите запрос отладки на ТВ.
3. Установите Android Platform Tools так, чтобы adb.exe был доступен в PATH.
4. Убедитесь, что INSTALL.cmd и MiTVAccessibilityRestorer-4.0.0.apk лежат рядом.
5. Запустите INSTALL.cmd.
6. На телевизоре откроется экран «Первичная настройка».
7. Проверьте компоненты и нажмите «Завершить настройку».

INSTALL.cmd самостоятельно:

- проверяет adb;
- запускает ADB server;
- требует ровно одно авторизованное устройство;
- выполняет adb install -r;
- выдаёт WRITE_SECURE_SETTINGS;
- проверяет readback granted=true;
- открывает com.mitv.accessibilityrestorer/.ControlActivity.

Скрипт НЕ выполняет uninstall автоматически и НЕ записывает start_3rd_app.

Если установка завершилась с INSTALL_FAILED_UPDATE_INCOMPATIBLE, установленная
версия подписана другим ключом. Скрипт покажет, но не выполнит команду:

adb uninstall com.mitv.accessibilityrestorer

Перед чистой установкой учитывайте: удаление Restorer не затрагивает настройки
Projectivy Launcher, Button Mapper, TorrServe или v2RayTun.

РУЧНАЯ УСТАНОВКА (ADVANCED)
---------------------------

adb install -r MiTVAccessibilityRestorer-4.0.0.apk
adb shell pm grant com.mitv.accessibilityrestorer android.permission.WRITE_SECURE_SETTINGS
adb shell am start -n com.mitv.accessibilityrestorer/.ControlActivity

В стандартном и ручном сценарии команда settings put system start_3rd_app не
требуется и не выполняется.

FIRST RUN UI
------------

Экран показывает:

- Button Mapper и его AccessibilityService как основной компонент;
- Projectivy Launcher и его AccessibilityService как основной компонент;
- TorrServe/GlobalTorrService как необязательную интеграцию;
- v2RayTun как необязательную интеграцию;
- фактическое состояние WRITE_SECURE_SETTINGS.

Если разрешение отсутствует, повторно запустите INSTALL.cmd либо выполните:

adb shell pm grant com.mitv.accessibilityrestorer android.permission.WRITE_SECURE_SETTINGS

Затем нажмите «Проверить снова». Кнопка «Диагностика» показывает число включённых
основных служб, VPN transport и результат последнего восстановления. Кнопка
«Восстановить сейчас» немедленно запускает существующий ручной STR recovery.

ПОДГОТОВКА CLEAN-INSTALL ТЕСТА БЕЗ start_3rd_app
------------------------------------------------

Vendor setting может пережить удаление APK. Перед тестом явно удалите его:

adb shell settings delete system start_3rd_app
adb shell settings get system start_3rd_app

Ожидаемый ответ:

null

После этого:

adb uninstall com.mitv.accessibilityrestorer

Установите новую версию через INSTALL.cmd. Скрипт не создаст start_3rd_app снова.

ПРОВЕРКА STR
------------

Выполните не менее трёх циклов:

Sleep -> 30 секунд -> Wake

Для v2RayTun выполните не менее пяти STR подряд. Ожидаемый обычный путь:

stopped=true + VPN=false -> SEND_ONCE -> CONNECTED

Допустимый путь при ошибке Xiaomi ConnectivityManager:

SecurityException -> 3 retries -> UNKNOWN -> stopped readback=true
-> SEND_ONCE_FALLBACK_STOPPED -> CONNECTED

Недопустимо после исправления:

stopped=true + VPN=UNKNOWN + vpnTriggerSent=false

Проверьте:

adb shell settings get system start_3rd_app
adb shell settings get secure enabled_accessibility_services
adb shell settings get secure accessibility_enabled
adb shell dumpsys package flar2.homebutton | grep -i stopped
adb shell dumpsys package com.spocky.projengmenu | grep -i stopped
adb shell dumpsys package ru.yourok.torrserve | grep -i stopped
adb shell dumpsys package com.v2raytun.android | grep -i stopped
adb shell dumpsys accessibility
adb shell dumpsys connectivity
adb shell ps -A
adb shell "logcat -d | grep -iE 'MiTVRestorer|accessibilityrestorer|AndroidRuntime'"

Ожидается:

- start_3rd_app остаётся null;
- Wake -> чёрный cover -> Projectivy примерно за 9 секунд;
- Button Mapper, Projectivy и TorrServe имеют stopped=false и Bound;
- Binding={} и Crashed={};
- процессы TorrServe/torrserver запущены;
- v2RayTun stopped=false, VPN transport/tun0 присутствует;
- физическая кнопка Home открывает Projectivy без кадра Xiaomi launcher.

COLD BOOT
---------

Cold boot использует прежние Direct Boot, LOCKED_BOOT_COMPLETED, BOOT_COMPLETED,
BOOT_COUNT, раннюю задержку 2500 ms и одноразовый fallback alarm 10000 ms.
TorrServe, v2RayTun, setup UI и новые delays в cold-boot ветку не добавлены.

ВАЖНО: новый APK versionCode 10 статически проверен, но физический cold boot и
clean-install STR без start_3rd_app должны быть проверены пользователем на ТВ.
